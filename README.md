## Featured Projects

### 🚀 Cognitic :  AI-Powered Meeting Insight & Project Management Workflow Automation Platform | LINK

**Tech Stack:**  
`Next.js 16`, `React 19`, `TypeScript`, `Prisma ORM`, `Neon PostgreSQL`, `Pinecone`, `Google Gemini AI`, `AWS Lambda`, `AWS S3`, `Clerk`, `Stripe`, `Svix`, `Resend`, `Slack Bolt SDK`

- Built a scalable AI-powered SaaS platform enabling automated meeting recording up to **2-hours**, speaker-labeled transcription, AI-generated summaries, and semantic knowledge retrieval for collaborative teams using serverless cloud architecture.

- Engineered a production-grade low-latency **RAG (Retrieval-Augmented Generation)** pipeline using **Google Gemini AI & Pinecone Vector Database**, implementing intelligent transcript chunking (**500-token embeddings**) to improve contextual search accuracy and enable real-time AI-powered meeting Q&A.

- Integrated **MeetingBaas APIs**, AWS Lambda, and asynchronous event-driven workflows to automate AI bot participation in **Google Meet & Zoom**, generating speaker-attributed transcripts, meeting recordings, summaries, and actionable insights while reducing manual documentation effort by **70%**.

- Developed one-click project management workflow automation integrations with **Slack, Jira, Asana, and Trello**, enabling automatic project/task creation directly from AI-extracted meeting action items and improving team productivity across collaborative environments.

- Designed scalable backend processing pipelines using **AWS Lambda, Svix webhooks, AWS S3, Pinecone, and Neon PostgreSQL** for secure transcript storage, vector indexing, webhook orchestration, Slack AI bot communication, and real-time delivery of meeting intelligence insights.

- Implemented secure authentication, subscription billing, and transactional email workflows using **Clerk, Stripe, and Resend**, supporting scalable SaaS onboarding, workspace management, and monetization infrastructure.

- Optimized backend query performance and vector retrieval latency to support concurrent workloads and fast semantic search across large-scale transcript datasets.
